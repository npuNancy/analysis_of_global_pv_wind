# Ward 层次聚类：相对损失率轨迹方案

对国家 (c)、情景 (s) 和年代 (t)，先计算

\[
R_{c,s,t}=100\times\frac{\sum_y L_{c,s,y}}{\sum_y G^{normal}_{c,s,y}}.
\]

分子是净出力损失，分母是正常情况下的应发电量。该指标按可发电量归一化，降低装机规模影响，同时保留当地资源条件和容量因子差异。

本方案使用三种情景和三个年代组成九维向量：

\[
\mathbf{x}_c=(R_{126,2030},R_{126,2040},R_{126,2050},R_{245,2030},R_{245,2040},R_{245,2050},R_{585,2030},R_{585,2040},R_{585,2050}).
\]

这不是情景差向量；SSP245 是独立的一组输入维度。

对九列分别在国家之间做 z-score：

\[
z_{c,j}=(x_{c,j}-\bar{x}_j)/s_j.
\]

这样可避免某个整体较高的年代或情景支配欧氏距离，同时保留国家在各情景—年代位置上的相对高低。不能对每个国家单独标准化，否则会删除国家总体风险水平信息。

开始时每个国家是一个类别。两个类别 (A,B) 的 Ward 合并代价为

\[
\Delta(A,B)=\frac{|A||B|}{|A|+|B|}\|\mu_A-\mu_B\|_2^2.
\]

每一步选择使类内平方和增加最小的一对类别，形成层次树，再在候选 (k=2,3,4,5) 处切树。

国家 (i) 的轮廓系数为 (s(i)=[b(i)-a(i)]/\max(a(i),b(i)))，其中 (a(i)) 是到本类其他国家的平均距离，(b(i)) 是到最近其他类的平均距离。程序先排除含单国家类别的常规候选，再比较平均轮廓系数；若最高分与更小类别数的分数差不超过0.05，采用更小的类别数。只有在所有候选都违反最小类别规模约束时才允许离群单国家类，并在诊断表中标记 `relaxed_min_cluster_size`。

稳定性用于检验类别是否依赖精确数值位置。程序对每个九维 z-score 向量加入标准差5%的高斯扰动，重复200次 Ward 聚类，通过最大重叠匹配解决类别编号交换；国家稳定率是其保持原类别的比例。

国家必须同时具有 SSP126、SSP245、SSP585 在2030s、2040s、2050s的完整十年数据，且正常应发电量分母大于0。缺失不填零、不插值，完整性和排除原因写入 `country_coverage.csv`。
