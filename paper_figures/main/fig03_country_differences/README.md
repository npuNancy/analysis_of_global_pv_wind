# Fig. 3：国家差异与全球代表性

世界地图统一使用简易圆柱（Plate Carrée）投影；经度范围为 −180° 至 180°，纬度范围为 −60° 至 85°，经纬度以度数标注。

## 科学问题与子图安排

本图检验全球容量加权的路径差能否代表各国的响应方向、时间演变，以及这些差异涉及多少国家和参考装机。采用六子图布局：

- **a–b：国家地图。** 左列风电、右列光伏，颜色为2050–2059年配对SSP585减配对SSP126的单位装机净损失差；模式方向不一致的国家加斜线，无可比结果使用浅灰色。
- **c–d：国家时间热图。** 两种技术采用相同的18国名单和顺序，对照2030–2039、2040–2049、2050–2059三个窗口；空心圆表示方向不明确。
- **e：国家分布与全球结果。** 每国一个四模式均值，国家等权；箱体为25%–75%分位数，中线为中位数，须至1.5倍四分位距内最远点。散点保留全部可比国家和异常值。菱形为全球容量加权路径差，端帽范围线为四模式最小值—最大值，不是置信区间。
- **f：国家数与容量份额。** 分别展示风电、光伏的国家数和参考容量比例。分类为SSP585损失更高、SSP126损失更高、方向不明确、无可比结果，四类互斥且合计100%。

地图和热图共用零中心对称线性色标。热图名单为SSP126的2050参考风光合计容量前12国，再补充6个具有至少3/4模式方向支持、绝对差值较大的案例。完整国家统计不受这18国选择影响。

## 指标口径与输入

损失为共同有效站点上带符号的事件并集净损失能量之和除以容量之和，单位为 MWh MW⁻¹ yr⁻¹。先逐模式计算各路径损失和路径差，再对 CANESM5、MPI-ESM1-2-HR、MRI-ESM2-0、BCC-CSM2-MR 四个模式等权平均。

设 $R_{c,s}$ 为气候情景 $c$、场站部署情景 $s$ 下的单位装机年均净损失，则：

$$
D=R_{585,585}-R_{126,126}
$$

这是同时包含气候与部署变化的综合路径差。正值表示配对SSP585损失更高，负值表示配对SSP126损失更高。至少3/4模式的非零差值与集合均值同号时，才归入相应的明确方向类别；该一致性不表示统计显著性。

## 风电13国、光伏12国无可比结果的原因

以下记录核对于 **2026-10-06**，对应 **2050容量快照和2050–2059窗口**。与 [Fig. 4的核验说明](../fig04_climate_deployment/README.md) 交叉参考后，再逐国检查本图成员表、逐模式结果和公共国家容量目录。

### 实际缺少什么

这25个技术—国家对象均具有正的SSP126参考容量，且配对SSP126损失 `R126` 的四模式结果完整；但**部署SSP585在2050快照中没有该国该技术的容量记录**，因此配对SSP585损失 `R585` 无法定义，路径差 `D` 也无法计算。

逐国核验均为：`R126` 有4个有限模式值，`R585` 和 `D` 各有0个有限模式值。当前缺失源于整个部署对照没有容量记录，不是某一个模式任务漏跑，也不是模式之间方向不一致。没有装机分母时，单位装机损失不能填成零。

“没有容量记录”仅指本项目输入场站资料、2050快照及国家空间归属后的目录结果，不代表现实世界没有对应技术的装机。
