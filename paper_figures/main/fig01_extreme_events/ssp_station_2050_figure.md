# 2050年代全球装机极端事件SSP对比图

## 绘图约定

- 问题：不同SSP的装机暴露、频次、完整事件平均持时和同步影响范围如何变化；事件及空间组成能否解释差异；装机与网格路径差是否同向。
- Python quantitative grid；左列风电，右列光伏；a–j五行；全部2050–2059，固定2050总装机快照。
- a/b：沿用全球网格图的四指标分组柱，每组三个SSP；柱高与模式极差除以同技术同指标的SSP126集合均值，柱顶标原始值；共用0.85–1.25截断纵轴及SSP126=1参考线；影响范围为同时受影响容量比例的时间P95。
- c/d：沿用全球网格图的单事件三SSP水平条形，条形连续完整、仅底部X轴标记断轴。按场站均值与完整模式范围，风电省略2–4及16–20（上限25），光伏省略4.5–8.5（上限15）day yr⁻¹，保留全部端点和模式极差；时间并集仅用于a/b，不将各事件相加替代并集。
- e/f：仅绘制SSP585−SSP126的国家暴露地图；两技术共用零中心±12.5 day yr⁻¹范围，参考fig01_ssp_grid_2050的地图；超限值用端点颜色、色条两端箭头表示，原始数据不截断。按有定义的国家汇总记录计，风电137/151（90.7%）、光伏138/152（90.8%）在色标范围内。
- g/h：七个固定代表国家（中国、美国、印度、德国、巴西、俄罗斯、澳大利亚）的SSP245−SSP126与SSP585−SSP126事件差、重叠修正和并集差热图，逐模式核算闭合。方框标最大绝对事件项，不作物理因果归因；地图保留所有有定义的国家，不按差异筛选代表国。
- i/j：四指标分别以原始单位比较装机和网格的三组路径差；点为四模式差值均值，误差线为差值min–max，零线区分方向。同步比例分别以容量和共同网格面积为分母，差值单位为百分点。
- 气候与装机SSP配对改变，不能称为纯气候效应；源SSP5-6.0布局对应station_ssp585。所有统计先在模式内计算，再等权汇总四模式；极差不是置信区间，模式同向不是显著性。
- 暴露为容量加权累计小时/24/年；频次为容量加权已知事件起点/年；持时为容量加权完整事件池均值；P95先在每个时刻合并各场站受影响容量，再求时间分位数。
- 复用已验收完整汇总，输入只读；保留双SSP、模式、技术、窗口、容量、国家与覆盖数据；不读取原始三小时序列。
- 世界地图Plate Carrée，范围[-180,180,-60,85]，China与Taiwan几何合并；缺失灰色，不填零。
- 输出16×16英寸分析组图，300 dpi PNG；完整图、ab/cd/ef/gh/ij五组合及a–j独立图。源数据写outputs/source_data/ssp_station_2050，图写outputs/fig01_ssp_station_2050*.png。
- 科学检查：四模式完整性、原始值复现已验收均值、三组模式内差、事件与重叠闭合、地图中国合并、覆盖和源文件身份、整图及全部独立图可读性。

## 图注

2050–2059年全球场站装机极端事件的SSP配对路径比较。左列风电，右列光伏。a/b为事件时间并集的四项指标，按同技术同指标SSP126集合均值归一，柱顶标原始值；纵轴范围0.85–1.25，模式范围同分母缩放，并非模式内比值极差；c/d为单事件暴露；e/f地图为SSP585−SSP126国家暴露差，统一色标±12.5 day yr⁻¹；g/h热图为SSP245−SSP126与SSP585−SSP126代表国家事件组成核算；i/j为装机和网格的同年代、同模式SSP差。柱/点及误差线分别表示四模式等权均值和min–max。所有事件暴露之和加重叠修正等于并集暴露，频次与分位数不具有该可加性。国别均值不能代表国内每个场站，地图面积不表示容量权重；七国不是全球穷尽划分。P95为同步受影响比例第95百分位，非最大值。低资源标签沿用各SSP自身2015–2024基线。源数据保留最大同步比例等额外指标，便于追溯。
