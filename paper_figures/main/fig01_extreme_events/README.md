# 图 1：极端事件的路径差异

科学问题：极端事件暴露的路径差异是否随空间、年代和事件类型变化？不预设情景排序。

采用 Python/matplotlib 两列三行的定量子图布局，左风电、右光伏。a–b 为主要空间证据：2050–2059 年事件并集小时的固定格点气候差（585−126，h yr⁻¹），以共同有效原始格点面积加权到 1°。浅灰空心圆表示 SSP126/2050 总容量快照，以3°网格汇总减少遮挡，面积正比于 GW。c–d 为三个十年窗口的全球容量加权气象事件并集暴露；三条配对路径分别使用自身部署与快照容量。e–f 为2050—2059 年的事件矩阵：面积表示绝对暴露，颜色表示相对配对126路径的模式内差再取四模式均值。各事件可能重叠，不作加法解释。

复用已验收的公共统计和 outputs/source_data/panel_ab.csv.gz、panel_cd.csv、panel_ef.csv，不重新读取三小时正式产品。prepare_data.py 检查完整性、归一化、四模式格点差、容量守恒和边界，补充逐模式地图差、容量气泡、覆盖表、矩阵模式内差与显示排序。事件按各技术基准暴露递减排序；共同类型保持相同相对顺序。具体顺序记录在 outputs/data_audit.json。四模式是 CANESM5、MPI-ESM1-2-HR、MRI-ESM2-0、BCC-CSM2-MR；中心为等权均值，范围为最小值至最大值，不作显著性推断。

PNG 采用183 mm × 165 mm画布、600 dpi。两地图共享色标，轨迹共享纵轴，矩阵共享面积与差值色标；地图容量面积与矩阵时数面积分别给图例。边界使用项目中的 Natural Earth 数据，将中国大陆与台湾的边界几何合并为中国分析单元。无有效气候格点保留为空白，不用陆地掩膜删除海上风电。地图只保留气候和容量两层；逐模式数据与一致性字段保留于源表。

从仓库根目录先执行 mkdir -p logs/paper_figures/fig01，再执行 sbatch paper_figures/main/fig01_extreme_events/plot.sh。默认绘图作业先执行本图核验及必要派生，再生成全部六个面板。单独核验可提交同目录 prepare_data.sh。每次使用4核、14 GB，在1866计算节点执行。

结果为 outputs/fig01.png、outputs/metadata.json、outputs/data_audit.json、outputs/caption.md 及派生源表。metadata.json 记录代码和源数据哈希；正式交付时补充视觉检查记录。气象暴露与年度损失产品（Loss）的有效事件窗口不同，前者不能代替损失；原始部署文件 SSP5-6.0 映射为 station_ssp585。
