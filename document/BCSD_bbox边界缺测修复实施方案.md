# BCSD bbox 边界缺测修复实施方案

- 日期：2026-07-09
- BCSD 项目：`/data6/yanxiaokai/project_climate/bcsd`
- 原始数据：`/data6/yanxiaokai/project_climate/bcsd/outputs`
- 修复对象：`uas`、`vas`、`tas`、`rsds`、`pr`
- 数据范围：现有 CMIP6 模式、26 国、`ssp126/ssp245/ssp585`
- 核心约束：不重跑 BCSD，不对现有 NetCDF 做原地写入，不填海洋缺测，不直接处理 CF

---

## 1. 结论

可以通过“跨国重叠网格补值 + 本国受控空间插值”修复 bbox 陆地边界缺测，且无需重跑 BCSD。建议采用以下固定优先级：

1. 只识别并修复 bbox 边界上的陆地结构性 `NaN`；
2. 优先使用同模式、同 SSP、同变量、同时间、同坐标的其他国家有效值；
3. 同一格点有多个合格国家提供值时，逐时间步取中位数；
4. 没有合格跨国数据时，使用本国原始有效陆地格点进行空间补值；
5. 空间补值距离初始硬上限为 2°，超过上限保持 `NaN`；
6. 海洋/海岸 `NaN`、内部非边界异常和时间维偶发缺测均不在本方案中修复。

该方案能显著减少计算量，但有两个不能回避的限制：

- 跨国 bbox 只覆盖部分国家和部分边界，不能解决全部边界缺测；
- 生成真实的修复后 NetCDF 仍必须读取并重写约 4.1 TB 数据。它省去的是 BCSD 计算，不是磁盘 I/O。现有文件采用覆盖完整空间范围的压缩时间块；边界格点贯穿全部时间，因此直接以 `r+` 修改也需要解压和重压缩几乎全部数据块，通常不会比顺序重写新文件快很多。

当前 `/data6` 约剩 570 GiB，无法安全容纳 NESM3 或 MIROC-ES2H 单个 SSP 的完整并行副本，更不能容纳全部约 4.1 TB 的修复副本。因此主方案是先生成轻量的“修复映射”，再按 `model × SSP × variable × overlap_group` 生成该组全部完整修复 NetCDF，整组预检通过后逐个原子替换原路径。任一事务只处理一个变量和一个区域组，严禁一次暂存同组的五个变量。

不采用“先生成整个模式 × SSP 的新目录，再删除旧目录并改名”的方式。该方式对 NESM3 和 MIROC-ES2H 空间不足，而且现有目录中三个 SSP 混放，无法通过一次目录改名只切换一个 SSP。

## 2. 已确认的决策

| 决策项 | 采用方案 |
|---|---|
| 修复范围 | 仅 bbox 边界上的陆地结构性 `NaN` |
| 海洋/海岸缺测 | 保持 `NaN` |
| 跨国数据优先级 | 高于本国插值 |
| 多国同时提供有效值 | 逐时间步取中位数 |
| 本国插值距离 | 初始最大 2°，通过验证决定是否收紧 |
| 修复变量 | `uas`、`vas`、`tas`、`rsds`、`pr` |
| CF | 不处理 |
| 文件更新方式 | 分组内源文件只读打开；整组临时文件通过预检后逐个原子替换原路径 |
| 事务粒度 | `model × SSP × variable × overlap_group` |
| 变量约束 | 一个事务只处理一个变量，不一次暂存同组五个变量 |
| 锁策略 | 不建立模式、SSP 或分组级 `IN_PROGRESS` 锁 |
| 修复脚本位置 | BCSD 项目中新建独立目录 |
| 本文交付范围 | 仅实施方案，不创建修复代码 |

## 3. 当前数据事实与实施前风险

### 3.1 当前存储和数据规模

截至 2026-07-09：

| 模式 | 区域目录数 | 磁盘占用 |
|---|---:|---:|
| `MIROC-ES2H` | 26 | 约 1.7 TB |
| `MPI-ESM1-2-HR` | 20 | 约 584 GB |
| `NESM3` | 26 | 约 1.9 TB |
| 合计 | — | 约 4.1 TB |

文件通常具有以下结构：

```text
outputs/{model}/{region}/{model}/
  {var}_3h_bcsd_on_0p1deg_{region}_{model}_{ssp}_2015-2060.nc
```

数据变量名为 `{var}_bcsd`，常见维度为：

```text
time × lat × lon
```

以 `NESM3/Brazil/uas/ssp126` 为例：

- `time = 134,416`
- `lat = 391`
- `lon = 392`
- 数据类型为 `float32`
- 压缩为 gzip
- 单文件约 49.6 GB
- 数据块为单时间步覆盖完整空间网格

### 3.2 当前数据并非严格的“3 模式 × 26 国 × 3 SSP × 5 变量”

实施前必须生成清单，禁止直接假定所有组合都存在：

- `MPI-ESM1-2-HR` 当前只有 20 个正常区域目录；
- `MIROC-ES2H/Australia` 和 `MIROC-ES2H/Brazil` 缺少三个 SSP 的 `tas`；
- 部分目录同时存在 `2015-2060` 和 `2015-2100` 文件；
- `NESM3/Poland/rsds/ssp126` 还存在一个 `2015-2016` 文件；
- 原有完整性检查脚本中 SSP 和变量列表被临时覆盖，不能直接作为本任务清单依据。
- 区域目录名以标准国家名为准：忽略任何目录名含下划线 `_` 的非标准区域目录（典型如 `{region}_repeated`、`{region}_<后缀>`，例如曾存在的 `MPI-ESM1-2-HR/India_repeated`）；标准区域名只用连字符 `-` 连接（如 `United-Kingdom`、`South-Korea`、`South-Africa`），不含 `_`。此类目录是重复或特殊处理产物，且其文件名内 region 字段与目录名不一致（`India_repeated/` 下文件 region 字段为 `India`），纳入清单会造成区域重复或误归类。注意：`{region}_repeated`、`_{region}_` 等模式只能用于**目录名**判断；文件名解析时 region 字段以标准 `{region}` 为准（文件名形如 `..._0p1deg_{region}_{model}_{ssp}_{period}.nc`），不可用 `_{region}_` 匹配文件名，否则会误伤全部标准文件。

本次默认只选择文件名时间范围严格等于 `2015-2060` 的文件。缺失组合必须记录为 `SOURCE_MISSING`，不得用其他模式、其他 SSP 或较短文件替代。

### 3.3 跨国补值是可行的，但必须验证

目标网格之间确实存在完全同坐标重叠。例如：

| 国家组合 | 完全同坐标重叠格点 |
|---|---:|
| Brazil–Chile | 12,388 |
| France–Germany | 1,927 |
| Spain–Portugal | 1,976 |
| Germany–Poland | 522 |
| Germany–Austria | 1,100 |

对 `NESM3/ssp126` 的 Brazil–Chile 三个时间点抽样显示：

- `uas/vas/tas/rsds` 在双方同时有效的 3,534 个重叠格点上数值完全一致；
- Brazil 可为 Chile 提供 1,699 个 Chile 缺测而 Brazil 有效的格点；
- Chile 可为 Brazil 提供 456 个反向补值格点；
- `pr` 在双方同时有效区域存在非零差异。

因此：

- 风、温度和辐射的跨国同坐标复制具有直接证据支持；
- 降水可能受各区域独立 BCSD 处理影响，必须单独通过一致性门槛；
- 上述抽样不能替代全部模式、SSP 和国家组合的自动验证。

### 3.4 固定区域分组

根据 `analysis_of_global_pv_wind/data/grid_of_regions` 中的真实网格坐标，固定使用以下九个 `overlap_group`：

| 分组 ID | 区域 | 网格关系 |
|---|---|---|
| `australia` | Australia | 与其他目标区域无重叠 |
| `india` | India | 与其他目标区域无重叠 |
| `vietnam` | Vietnam | 与其他目标区域无重叠 |
| `egypt` | Egypt | 与其他目标区域无重叠 |
| `south_africa` | South-Africa | 与其他目标区域无重叠 |
| `mexico` | México | 与其他目标区域无重叠 |
| `brazil_chile` | Brazil、Chile | 完全同坐标重叠 12,388 个格点 |
| `japan_south_korea` | Japan、South-Korea | 重叠 3,402 个格点；South-Korea 的全部网格包含在 Japan 网格内 |
| `europe_west_asia` | Austria、Denmark、France、Germany、Ireland、Italy、Netherlands、Poland、Portugal、Romania、Spain、Sweden、Ukraine、United-Kingdom、Greece、Turkey | 统一作为欧洲+西亚处理组 |

`europe_west_asia` 内部实际包含“欧洲 14 区域连通块”和独立的 `Greece–Turkey` 重叠对；两部分之间没有完全同坐标重叠，但为简化运行管理，统一放入一个事务分组。不存在重叠的两部分不得互相提供数据。

分组清单应写入版本化配置。建立重叠索引时必须用网格文件重新验证：

- 单独区域不得出现新的跨区重叠；
- 固定重叠数量或包含关系发生变化时必须停止并更新配置；
- 供体候选仍以实际完全同坐标索引为准，不能仅凭处于同一分组就互相供值；
- `NAM-12` 和 `china` 不属于本次 26 国 BCSD 修复分组。

## 5. 数据不变性与版本规则

### 5.1 禁止对现有文件原地写入

程序层面必须同时实施以下保护：

- 事务粒度严格限制为 `model × SSP × variable × overlap_group`；
- 分组内所有目标和供体 NetCDF 在临时文件生成阶段始终以只读模式打开并保持原始状态；
- 禁止使用 NetCDF `r+`、xarray 追加模式、`ncks -O` 或 `cdo -O` 直接修改源文件；
- 在 `boundary_nan_repair/tmp` 中生成该分组、该变量的全部 `*.partial`；
- 严禁在同一事务中生成或暂存五个变量；
- 分组内全部临时文件完成关闭、同步和预检后，才能进入替换步骤；
- 预检通过后为分组内所有原文件建立回滚硬链接，但绝不通过硬链接或原路径原地写数据；
- 使用同文件系统的 `os.replace()` 逐个替换分组成员；多文件替换不是单次原子操作；
- 全部分组成员替换后执行分组级 QC；任一成员失败都恢复该组已经替换的全部文件；
- 分组级 QC 通过后才删除该组全部回滚硬链接；
- 不设置模式、SSP 或分组级 `IN_PROGRESS` 锁；运行期间由操作流程保证没有下游读取。

必须为每个分组事务及其成员文件记录状态：

```text
PLANNED → WRITING_ALL → PRECHECKED_ALL → BACKED_UP
       → REPLACING → GROUP_QC → VERIFIED
                         └────→ ROLLED_BACK
```

异常恢复依赖分组事务记录、成员状态和回滚硬链接，而不是依赖目录级锁。`--resume` 必须先恢复或继续当前未完成分组，不能直接开始另一个分组。

### 5.2 输入指纹

对每个源文件记录：

- 绝对路径；
- 文件大小和修改时间；
- 模式、国家、变量、SSP 和时间范围；
- 数据变量名、维度、数据类型、单位；
- `time/lat/lon` 长度与坐标摘要；
- `time/lat/lon` 坐标数组哈希；
- 全局属性中的 `history` 和 `Conventions`。

不建议默认计算 4.1 TB 文件的完整 SHA-256，这会额外完整读取全部数据。坐标哈希、文件大小和修改时间足以作为日常失效检测；正式归档时可另行执行完整哈希。

修复映射必须绑定替换前的输入指纹。分组内所有成员的修复映射必须在写任何临时 NetCDF 前生成。文件替换后同时记录原指纹、新指纹、分组 ID 和事务状态；旧映射不能用于再次修复已经替换的文件。

同一分组内的全部临时文件必须从尚未替换的原始供体读取，禁止先替换一个国家后再用其修复结果生成另一个国家。跨分组不存在供体关系。

## 6. 修复对象的严格定义

### 6.1 不使用“任意陆地 NaN”作为修复条件

如果把全部陆地 `NaN` 都填掉，可能误填：

- 非 bbox 边界的内部异常；
- 某个变量独有的计算问题；
- 单个时间步的偶发缺测；
- 海陆掩码误差造成的海岸格点。

因此目标格点必须同时满足：

```text
目标格点
= 结构性缺测
∩ 陆地
∩ 与 bbox 缺测边界连通
∩ 原文件目标位置为 NaN
```

### 6.2 结构性缺测

`step06_apply_sd_3h.py` 使用静态 `mask_src`：

```python
mask_src = ds_hi[var].isel(time=0).notnull()
part = part.where(mask_src)
```

这意味着根因所致的边界缺测在时间维上是静态的。建议按以下方式识别：

1. 读取首、尾和均匀分布的至少 16 个时间点；
2. 只有这些时间点全部为 `NaN` 的格点才进入结构性候选；
3. 比较同一国家、模式下五变量和三个 SSP 的候选掩码；
4. 多数文件一致的空间掩码作为边界候选；
5. 映射应用时仍执行 `where(source is NaN, repaired, source)`，永远不覆盖任何原始有效值。

如果不同变量或 SSP 的掩码明显不一致，必须为每个文件独立建图，并在 QC 中报警，不能强行使用统一掩码。

### 6.3 陆地判定

统一使用：

```text
analysis_of_global_pv_wind/data/era5land/lsm_0.1x0.1.nc
```

规则为：

```text
lsm >= 0.5 → 陆地
lsm < 0.5  → 海洋
```

坐标采用最近邻匹配，匹配距离不得超过 0.051°。超出容差的格点标为 `LSM_UNMATCHED`，保持 `NaN`。

### 6.4 bbox 边界连通性

在二维结构性缺测掩码上使用四邻域连通域：

- 与网格最外圈相连的缺测分量视为 bbox 边界候选；
- 再与 `lsm >= 0.5` 相交，得到最终陆地边界缺测；
- 不与外圈连通的内部空洞不自动修复；
- 对跨 0° 经线的区域先将经度循环排序，禁止把 359.9° 和 0° 错判为遥远位置。

最终必须分别输出：

- 陆地边界目标数；
- 海洋缺测数；
- 内部缺测数；
- LSM 无法匹配数；
- 各边界方向的缺测带宽。

## 7. 第一优先级：跨国重叠网格补值

### 7.1 候选约束

只有同时满足以下条件的文件才能互为供体：

- 模式相同；
- SSP 相同；
- 变量相同；
- 时间范围、时间长度、时间值和 calendar 完全一致；
- 单位一致；
- 经纬度规范化后存在完全同坐标格点；
- 供体格点为原始有效值，不允许使用供体自身的插值结果；
- 供体通过该变量的重叠区一致性检验。

禁止以下替代：

- 不同 CMIP6 模式之间补值；
- 不同 SSP 之间补值；
- 用 `uas` 或 `vas` 互相替代；
- 用 ERA5-Land 直接填未来 BCSD；
- 用已经修复的国家继续填另一个国家，形成级联传播。

### 7.2 坐标匹配

坐标统一为：

- 经度转换至 `[0, 360)`；
- 坐标比较精度为 `1e-6°`；
- 优先使用完全同坐标映射；
- 不在跨国阶段进行最近邻重采样。

完全同坐标是跨国复制可信度高于本国外推的主要原因。

### 7.3 供体一致性检验

对每个 `(model, ssp, variable, target_country, donor_country)`，在双方都有效的重叠格点上抽取：

- 至少 16 个覆盖季节和日内时刻的时间点；
- 至少 100 个共同有效格点；不足时标为证据不足；
- 中位差、平均偏差、MAE、RMSE、P95 绝对差；
- P05/P50/P95 分位数差异。

变量专项检查：

| 变量 | 额外检查 |
|---|---|
| `uas/vas` | 分量误差，以及合成风速和风向误差 |
| `tas` | 偏差、RMSE、极端温度分位数 |
| `rsds` | 白天样本偏差、夜间零值一致率、非负性 |
| `pr` | 干湿事件一致率、累计降水偏差、P95/P99 湿时段强度 |

不能先凭经验固定一个适用于所有变量的绝对阈值。阈值应在试点交叉验证中冻结，并写入 `config.yaml`。最低规则是：

- 样本数不足的国家对不作为跨国供体；
- 误差显著高于本国空间插值交叉验证误差的供体不采用；
- `pr` 必须独立通过干湿事件和累计量检验；
- 任何检验失败都只会降级到本国插值，不会中止其他国家。

### 7.4 单供体和多供体

每个目标格点按以下规则处理：

1. 收集所有通过检验且在该格点原始有效的国家；
2. 只有一个供体时，直接复制该供体的同坐标值；
3. 有两个或更多供体时，逐时间步取有限值中位数；
4. 某时间步所有供体均缺测时，进入本国插值；
5. 不设置固定国家优先级。

中位数比平均数更能抑制某个区域独立 BCSD 处理产生的异常偏差。

## 8. 第二优先级：本国受控空间补值

### 8.1 通用规则

只对跨国步骤后仍未解决的目标格点执行本国空间补值：

- 邻居只能来自该国原始有效陆地格点；
- 禁止使用新填充值作为后续邻居；
- 使用球面距离，不直接把经纬度当平面坐标；
- 最大距离初始为 2°；
- 优先限制在同一连续陆地区域，避免跨海复制；
- 找不到合格邻居时保持 `NaN`；
- 不做任何时间插值。

### 8.2 建议的变量方法

| 变量 | 默认方法 | 说明 |
|---|---|---|
| `uas` | 4 邻点 IDW | 与 `vas` 使用完全相同的邻居和权重 |
| `vas` | 4 邻点 IDW | 避免两个风分量来自不同空间位置 |
| `tas` | 4 邻点 IDW | 连续变量，适合局部平滑 |
| `rsds` | 4 邻点 IDW | 保留日内时间变化，结果保持非负 |
| `pr` | 最近原始有效陆地格点 | 避免 IDW 人为增加毛毛雨并削弱极端降水 |

IDW 权重建议为：

```text
w_i = 1 / max(d_i, ε)^2
value = Σ(w_i × value_i) / Σw_i
```

其中：

- `k = 4` 为初始值；
- `ε` 仅用于数值保护；
- 邻居和权重是二维静态映射，只计算一次；
- 每个时间块复用同一映射。

必须在交叉验证中比较：

- 最近邻；
- IDW，`k = 4`；
- IDW，`k = 8`；
- 1°、1.5° 和 2° 最大距离。

最终选择应按变量确定，不要求五个变量使用同一种算法。若 2° 样本误差明显恶化，应收紧距离，不能为了填满所有格点而牺牲可信度。

### 8.3 物理约束

- `rsds >= 0`；
- `pr >= 0`；
- `tas` 不施加人为截断，但执行合理范围报警；
- `uas/vas` 允许正负值；
- 对 `uas/vas` 额外检查修复后的风速与风向突变；
- 不修改源变量单位。

正权重 IDW 本身不会超出邻居值范围。若仍出现非物理值，应视为源数据或单位问题，不能静默截断后通过 QC。

## 9. 修复映射与分组事务式替换

### 9.1 修复映射内容

每个目标区域至少保存以下二维信息：

| 字段 | 含义 |
|---|---|
| `target_flat_index` | 目标格点在 `lat × lon` 中的索引 |
| `method` | 跨国单供体、多供体中位数、IDW、降水最近邻或未解决 |
| `donor_region_ids` | 跨国供体国家 |
| `donor_flat_indices` | 供体同坐标索引 |
| `local_neighbor_indices` | 本国插值邻居 |
| `local_weights` | 本国插值权重 |
| `max_distance_deg` | 最远邻居距离 |
| `lsm` | 目标格点陆地比例 |
| `reason_if_unresolved` | 未解决原因 |
| `source_fingerprint` | 绑定的输入版本 |

方法编码建议：

| 编码 | 含义 |
|---:|---|
| 0 | 原始有效值，不处理 |
| 1 | 单个跨国同坐标供体 |
| 2 | 多个跨国供体中位数 |
| 3 | 本国 IDW |
| 4 | 本国最近邻，主要用于 `pr` |
| 255 | 目标格点仍无法解决 |

修复映射不存储 46 年的填充值，只保存空间索引、权重和来源，因此体积远小于完整 NetCDF。

### 9.2 分块应用

应用程序以 `model × SSP × variable × overlap_group` 为唯一事务粒度。一个事务只处理一个变量；批量调度器可以依次运行五个变量，但不得把五个变量放入同一事务或同时暂存。

开始写出前，先为分组内所有现存目标文件生成修复映射，并只读打开该组所需的全部原始目标和供体文件。随后对每个目标文件按连续时间块执行：

```text
校验目标和供体的替换前指纹或事务记录
→ 只读打开目标源文件
→ 顺序读取目标时间块
→ 读取必要的跨国供体格点
→ 应用跨国修复
→ 对剩余目标应用本国空间映射
→ 写入压缩的 *.partial NetCDF
```

任何原始非 `NaN` 值都必须原样写入。在分组内全部临时文件生成并预检完成前，任何原文件都不得被替换，以保证所有跨国供体来自同一批原始数据。

### 9.3 校验和原子替换

临时文件保持原文件名和目录语义，但位于临时目录，例如：

```text
boundary_nan_repair/tmp/
  {model}/{region}/{model}/
    {source_filename}.partial
```

每个分组事务必须按以下顺序提交：

1. 为分组内所有现存文件提前生成并校验修复映射；
2. 保持所有供体文件为原始状态并只读打开；
3. 生成该分组、该变量的全部临时 NetCDF；
4. 关闭并 `fsync` 全部临时文件；
5. 对全部临时文件执行预检，包括维度、坐标、时间、calendar、单位、压缩设置、关键属性、原始有限值零改动、目标填充数、保留缺测数、物理范围和首尾时间块；
6. 只有全部成员预检通过后，才为分组内所有原文件建立回滚硬链接；
7. 使用 `os.replace(partial, source)` 逐个替换分组成员，并记录每个成员的替换状态；
8. 全部替换后重新打开所有原路径，执行分组级 QC；
9. 任一成员失败则用回滚硬链接恢复整个分组，包括已经通过单文件检查的成员；
10. 全组通过后删除全部回滚硬链接，并把分组事务标为 `VERIFIED`。

输出必须完整保留坐标、单位和关键全局属性，并新增修复方法、原输入指纹、配置版本、分组 ID 和修复统计属性。写出前按“该分组单变量全部临时文件”估算峰值空间；不得先生成整个模式 × SSP 的完整副本，也不得一次暂存一个分组的五个变量。

## 10. 交叉验证与方法冻结

### 10.1 为什么必须先做挖洞验证

真实缺测位置没有真值，不能直接评价插值误差。因此需要在邻近有效边界带上人为隐藏已知值，再用相同方法恢复。

### 10.2 抽样设计

按以下维度分层抽样：

- 模式；
- 国家；
- SSP；
- 变量；
- 季节；
- 8 个三小时时次；
- 与最近有效格点距离：`0–0.5°`、`0.5–1°`、`1–1.5°`、`1.5–2°`；
- 地形和海岸条件可用时进一步分层。

推荐试点区域：

- Brazil–Chile：大范围跨国重叠；
- France–Germany–Austria–Poland：多个供体和多国重叠；
- Japan：岛屿、海岸和大范围无供体情形；
- South Africa 或 Egypt：主要依赖本国边界补值。

先用 `NESM3/ssp126/2050` 完成五变量试点，再扩展到其他模式和 SSP。

### 10.3 指标

| 变量 | 主要指标 |
|---|---|
| `uas/vas` | 分量 MAE/RMSE、风速 MAE、风向误差、P95 风速误差 |
| `tas` | MAE、RMSE、平均偏差、P05/P95 偏差 |
| `rsds` | 白天 MAE、平均偏差、累计辐射偏差、夜间零值一致率 |
| `pr` | 干湿事件准确率、累计量偏差、湿时段 MAE、P95/P99 偏差 |

除总体指标外，必须绘制误差随补值距离增加的曲线。2° 只是最大候选上限，不是必须使用到 2°。

### 10.4 方法选择规则

每个变量选择满足以下条件的最简单方法：

1. 跨国同坐标方法的误差不得显著劣于本国方法；
2. 本国方法在更远距离段不能出现明显失控；
3. `pr` 的干湿事件和极端值不能因平滑明显恶化；
4. 方法和阈值一经试点冻结，批量阶段不得按国家人工临时调整；
5. 如确需国家级例外，必须写入版本化配置并说明原因。

## 11. 质量控制与验收标准

### 11.1 硬性正确性条件

任何一项失败，该文件均不得标记为通过：

- 原始有限值零改动；
- 原始海洋 `NaN` 仍为 `NaN`；
- 内部非边界缺测未被填充；
- 所有跨国值来自同模式、同 SSP、同变量、同时间；
- 所有空间供体距离不超过冻结后的上限；
- 时间、经纬度、calendar、单位和维度不变；
- `rsds/pr` 无负值；
- 输出文件可重新打开，时间首尾和长度正确；
- 修复映射的源指纹与当前源文件一致；
- 输出不是全 `NaN`，也没有异常常数场。

### 11.2 覆盖率指标

每个文件输出：

```text
n_target_land_boundary
n_filled_cross_country_single
n_filled_cross_country_multi
n_filled_local
n_unresolved
fill_rate
max_and_p95_fill_distance
```

覆盖率是透明报告项，不以“100% 填满”为目标。超过 2° 或缺乏可信供体的格点宁可保留 `NaN`。

还应输出国家级和场站级指标：

- 修复前后陆地边界 `NaN` 格点数；
- 修复前后落在缺测格点上的风光场站数；
- 修复前后受影响装机容量；
- 仍未解决场站及原因。

场站级统计只用于评价气象修复效果，不在本方案中计算或修改 CF。

#### 11.2.1 场站级 `0/nan` 占比的统计口径

`RQ0/plot_stations_S0E2_zero_or_nan.py --plot-scope met` 输出的 BCSD 气象场站异常占比定义为：

```text
bad_ratio = n_bad / n_covered
```

其中：

- `n_bad`：被判定有 BCSD 气象覆盖的场站中，按场站经纬度 nearest 到 BCSD 网格后，2050 年年均气象值为 `NaN` 或严格等于 `0` 的场站数；
- `n_covered = n_bad + n_ok`：脚本按 `AREA_DICT` 矩形 bbox 判定落在 26 个 BCSD 国家区域内、因此纳入 BCSD 气象评价分母的场站数；
- 不进入分母的场站：`China`、`NAM-12` 和 `outside`，因为本次 BCSD 气象修复只覆盖 26 国，不覆盖 China 或 NAM-12；
- wind 气象值为年均 RMS 风速：`sqrt(mean(uas²) + mean(vas²))`；
- solar 气象值为 `rsds_bcsd` 的 2050 年均值。

因此该指标衡量的是“场站 nearest 到当前 BCSD 气象网格后是否仍取到 `NaN/0`”，不是“修复映射目标格点的填充率”。两者口径不同，不能直接等同。

以 `NESM3 / ssp126 / 2050` 修复后为例：

| 技术 | `NaN` | `0` | 正常 | `n_covered` | `bad_ratio` |
|---|---:|---:|---:|---:|---:|
| wind | 8,585 | 0 | 21,894 | 30,479 | 28.17% |
| solar | 5,782 | 0 | 22,141 | 27,923 | 20.71% |

该结果说明当前剩余异常全部来自 `NaN`，不是气象值等于 `0`。

修复前后对比如下：

| 技术 | 修复前 `n_bad / n_covered` | 修复前占比 | 修复后 `n_bad / n_covered` | 修复后占比 | 下降 |
|---|---:|---:|---:|---:|---:|
| wind | 12,107 / 30,479 | 39.72% | 8,585 / 30,479 | 28.17% | -11.55 percentage points |
| solar | 8,656 / 27,923 | 31.00% | 5,782 / 27,923 | 20.71% | -10.29 percentage points |

#### 11.2.2 修复后场站级 `NaN` 占比仍较高的原因

修复后场站级 `NaN` 占比仍高于 20%，不能直接解释为 bbox 边界修复失败。主要原因是该统计口径比本方案的修复目标更宽：

1. 本方案只修复 bbox 边界上的陆地结构性 `NaN`，不承诺填补所有陆地 `NaN`、海岸/海洋 `NaN`、内部异常或超出可信供体距离的缺测。
2. 场站脚本使用矩形 bbox 做区域归属，不使用精确国界或实际 BCSD 有效网格 mask。场站落入某个国家 bbox，不代表 nearest 到该国家 BCSD 文件时一定能取得有效值。
3. 区域存在重叠或包含关系时，脚本按 `AREA_DICT` 顺序取第一个命中的区域。典型情况是 `Japan–South-Korea`：`South-Korea` 网格完全包含在 `Japan` 网格内，而脚本先判断 `Japan`，会导致 South-Korea 场站被归入 Japan 后再去 Japan 文件取值，从而产生额外 `NaN`。
4. 当前场站级 `bad` 统计未区分 `NaN` 来源：修复目标边界缺测、bbox 归属误差、国家文件有效网格范围之外、海陆边界 nearest 误差等都会被统一计为 `bad`。

`NESM3 / ssp126 / 2050` 修复后，剩余 `NaN` 明显集中在少数区域，而不是在全部区域均匀残留。例如：

| 技术 | 高残留区域示例 |
|---|---|
| wind | Japan 100.00%、United Kingdom 83.25%、Sweden 67.76%、Italy 64.54%、Turkey 56.30%、México 53.26% |
| solar | Sweden 100.00%、United Kingdom 85.15%、Italy 71.92%、India 71.31%、México 47.60% |

因此，场站级指标应作为“修复后用户侧取值仍可能遇到缺测”的风险报告项，而不是单独作为本方案是否通过的硬性判据。若需要进一步降低场站级 `NaN`，应另建一个场站取值侧修正任务，例如：

- 对场站区域归属改用实际有效网格 mask，而不是仅用 bbox；
- 对重叠/包含区域使用所有候选国家文件查找最近有效值；
- 分离报告“修复目标格点未填充”和“场站归属/nearest 采样导致取到 `NaN`”两类原因。

### 11.3 跨边界连续性

对修复带内外分别计算：

- 相邻格点梯度分布；
- 修复边界两侧均值跳变；
- 时间序列均值、方差和极值；
- 跨国供体与本国有效区的接缝。

如果修复后产生比原始有效区 P99 梯度更大的系统性接缝，应回退该供体或收紧距离。

## 13. 性能和资源策略

### 13.1 避免全空间重复计算

- 重叠索引、目标掩码、邻居和权重均只计算一次；
- 不为每个时间步重新运行 KDTree；
- 不把完整 46 年数据载入内存；
- 按连续时间块流式处理；
- 只读取目标格点所需的供体空间范围。

### 13.2 并发

瓶颈主要是磁盘 I/O，而非 CPU。默认：

- 清单、掩码和修复映射等只读阶段可并行；
- 同一时刻只允许一个 `model × SSP × variable × overlap_group` 进入正式写出或替换阶段；
- 分组内部默认顺序生成临时文件；只有实测证明空间和 I/O 均安全时，才允许并行生成小区域成员；
- 不同时读取多个 40–50 GB 文件做全时间扫描；
- 日志记录实际吞吐量，但不得在没有重新验证空间和事务安全性的情况下提高写入并发。

高并发可能让机械上看似“多任务同时运行”，实际总耗时更长，并加剧 99% 磁盘占用下的风险。

### 13.3 临时空间

- 临时文件和回滚硬链接放在 `boundary_nan_repair/tmp`，并确保与 `outputs` 位于同一文件系统；
- 开始前估算该分组单变量全部输入、预计输出和峰值临时空间；
- 可用空间不足时立即拒绝运行；
- 每次只暂存一个分组的一个变量，严禁同时暂存同组五个变量；
- 分组成功后删除全部 `.partial` 和回滚硬链接；

## 16. 不采用的方案

### 16.1 直接对全部 `NaN` 做二维插值

不采用。它会填海洋、内部异常和非结构性缺测，无法区分缺测成因。

### 16.2 用最近国家的非同坐标格点直接覆盖

不采用。跨国阶段仅接受完全同坐标；非同坐标问题统一进入本国受控空间补值。

### 16.3 让修复结果继续充当其他国家供体

不采用。级联补值会放大误差并失去可追溯性。

### 16.4 对五个变量统一使用 IDW

不采用。降水是零膨胀且极端敏感的变量，默认使用最近邻，并通过专项验证。

### 16.5 当前磁盘上生成完整并行修复副本

不采用。完整约 4.1 TB 副本远超当前约 570 GiB 可用空间；NESM3 单个 SSP 约 522–569 GiB，MIROC-ES2H 单个 SSP 约 540–546 GiB，也没有足够安全余量。

### 16.6 直接原地修改现有 NetCDF

不采用 `r+`、`ncks -O` 或 `cdo -O` 对现有文件直接写入。压缩时间块仍需整体解压和重压缩，性能收益有限，但中断损坏、文件内部碎片和不可回滚风险明显。采用“新文件完整写出并校验后原子替换原路径”。

### 16.7 整个模式 × SSP 目录切换

不采用。单个大模式 SSP 已接近全部剩余空间，而且三个 SSP 文件混放在国家/模式目录中，无法通过一次目录改名只切换目标 SSP。

### 16.8 有跨国依赖时逐文件生成后立即替换

不采用。先替换某个国家再生成同组其他国家，会使后续供体指纹和数据世代发生变化，并增加修复值级联传播的控制复杂度。同组全部临时文件必须从原始供体生成，整组预检通过后才能开始替换。

### 16.9 同一分组一次暂存五个变量

不采用。跨国供体依赖只发生在相同变量之间，同时暂存五个变量不会提高正确性，却会显著增加峰值空间、失败回滚范围和重跑成本。

## 17. 最终完成定义

本任务只有同时满足以下条件才算完成：

- 全部现存且唯一可识别的目标文件进入清单；
- 缺失和歧义组合有明确报告；
- 五变量方法均经过挖洞验证并冻结；
- 所有可处理组合都生成版本化修复映射；
- 原始有效值、海洋 `NaN` 和内部缺测零误改；
- 每个修复格点都能追溯到供体或本国邻居及距离；
- 未解决格点有明确原因；
- 至少一个跨国试点和一个本国插值试点完成临时文件端到端 QC；
- 所有 `model × SSP × variable × overlap_group` 事务均达到 `VERIFIED`，其成员原路径指向完整修复后的真实 NetCDF；
- 每个分组事务及成员文件均记录分组 ID、原指纹、新指纹、修复统计和事务结果；
- 不存在遗留的 `.partial` 或回滚硬链接；
- 完整 QC 报告记录格点级和场站级改善；
- 未生成或保留整套并行物理副本。

该完成定义要求在原路径获得真实修复 NetCDF，同时通过单变量分组事务把额外空间限制在一个 `overlap_group` 的单变量规模。
