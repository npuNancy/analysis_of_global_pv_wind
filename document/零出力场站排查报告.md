# 零出力场站排查报告

- **日期**：2026-06-25
- **更新**：2026-07-02
- **排查范围**：`RQ0`、`RQ1`、`ref_code/bcsd`、`ref_code/calculate_bcsd_cfs`、`ref_code/calculate_wind_solar_out`
- **核心口径**：`NESM3 / 2050`，场站来自 `data/stations`，CF 与出力来自 `data/cfs`、`data/wind_solar_output`

---

## 一、问题描述

在 `RQ1/plot_RQ1_cf.py` 和 `RQ1/plot_RQ1_cf_capacity_quadrant.py` 中，绘图前会过滤 `CF = 0` 或 `generation = 0` 的场站。2050 年被过滤的零出力场站占比如下：

| 技术 | 情景 | 零出力场站占比 | 零出力装机占比 |
|------|------|----------:|----------:|
| 光伏 | SSP1-2.6 | 21.7% | 21.5% |
| 光伏 | SSP2-4.5 | 23.6% | 19.6% |
| 光伏 | SSP5-8.5 | 31.6% | 44.1% |
| 风电 | SSP1-2.6 | 25.1% | 22.1% |
| 风电 | SSP2-4.5 | 26.8% | 24.4% |
| 风电 | SSP5-8.5 | 24.4% | 20.5% |

2030、2040 年比例相近，说明这不是某个目标年份独有的问题，而是气象/CF 数据生产链路中的系统性缺测传播。

---

## 二、结论

**零出力场站不是物理上的“全年不发电”，而是 BCSD 气象缺测在 CF 计算阶段被静默转成 0 后，继续传递到场站出力和 RQ1 年度统计的结果。**

更精确地说，问题由两层叠加造成：

1. **BCSD 气象在部分 0.1° 网格上为 `NaN`**。这些缺测既包括 ERA5-Land 海洋/海岸缺测，也包括每个国家 bbox 边缘的陆地缺测。场站层面最主要的是后者：`RQ0/analysis_zero_nan_q1_q2` 显示，26 国内落在气象 `NaN` 上的场站中，风电 **98.86%**、光伏 **99.33%** 属于陆地边界缺测。
2. **BCSD CF 脚本把输入 `NaN` 转为 0**。`ref_code/calculate_bcsd_cfs/S01E01_Simulate_Solar_CF_BCSD.py` 和 `S01E02_Simulate_Wind_CF_BCSD.py` 在单位转换阶段使用 `np.nan_to_num(..., nan=0.0)`，后续只用 `global_land_mask` 把海洋重新置为 `NaN`。因此，陆地边界缺测没有被恢复成 `NaN`，而是保留为 `CF = 0`。

这解释了为什么下游看到的是“零出力”而不是“无数据”：`station_output_calculator_0p1deg.py` 对 `CF = NaN` 输出 `power = NaN`，但对 `CF = 0` 输出 `power = 0`；`prepare_RQ1_data.py` 只排除全年全 `NaN` 的场站，不排除全年全 0 的场站。

---

## 三、关键证据

### 3.1 气象与 CF 的异常场站一一对应

`RQ0/outputs/plot_stations/plot_stations_S0E2_zero_or_nan/stats_zero_or_nan_NESM3_ssp126_2050.csv`：

| 数据 | 技术 | 0/nan 场站 | 正常场站 | 覆盖场站 | 异常占比 |
|------|------|----------:|----------:|----------:|----------:|
| 气象 | wind  | 12,107 | 18,372 | 30,479 | 39.72% |
| 气象 | solar | 8,656  | 19,267 | 27,923 | 31.00% |
| CF   | wind  | 13,478 | 45,465 | 58,943 | 22.87% |
| CF   | solar | 10,721 | 41,832 | 52,553 | 20.40% |

气象与 CF 的比例不同，主要是分母不同：气象只覆盖 26 国，CF 覆盖 26 国 + China + NAM-12。`RQ0/analysis_zero_nan_q1_q2/outputs/q1_decomposition.csv` 把 CF 限定到 26 国后，比例与气象逐位相同：

| 技术 | 气象覆盖 | CF 覆盖 | 气象 bad | CF bad 总计 | CF bad 拆解（26国 / China / NAM） | CF 限 26 国 |
|------|--------:|--------:|---------:|------------:|----------------------------------:|------------:|
| wind  | 30,479 | 58,943 | 12,107 | 13,478 | 12,107 / 1,371 / 0 | 39.72% |
| solar | 27,923 | 52,553 | 8,656  | 10,156* | 8,656 / 1,500 / 0 | 31.00% |

`q1_station_agreement.csv` 进一步显示，26 国同站矩阵中 `met bad` 与 `CF bad` 完全一致：

| 技术 | 两边都 bad | 仅气象 bad | 仅 CF bad | 两边都 ok | 一致率 |
|------|-----------:|-----------:|----------:|----------:|------:|
| wind  | 12,107 | 0 | 0 | 18,372 | 100% |
| solar | 8,656  | 0 | 0 | 19,267 | 100% |

> *注：`q1_decomposition.csv` 中 solar CF bad 为 10,156，而历史 S0E2 CSV 为 10,721，差异来自部分 China/NAM solar CF 文件后续更新；26 国同口径部分仍完全一致，不影响根因判断。

### 3.2 场站层面的气象缺测几乎都是陆地边界缺测

`RQ0/analysis_zero_nan_q1_q2/outputs/q2_stations_nan_landsea.csv`：

| 技术 | 26 国覆盖场站 | 气象 NaN 场站 | 陆地边界 NaN | 海洋/海岸 NaN | 陆地边界占比 |
|------|-------------:|--------------:|-------------:|--------------:|-------------:|
| wind  | 30,479 | 12,107 | 11,969 | 138 | 98.86% |
| solar | 27,923 | 8,656  | 8,598  | 58  | 99.33% |

这说明，虽然网格层面海洋 `NaN` 很多，但场站选址本身主要在陆地上，因此真正命中场站的是“陆地上没有 BCSD 气象值”的边界缺测。

### 3.3 典型区域

澳大利亚示例中，BCSD 网格总数 140,415 个，全时段 `NaN` 格点 87,277 个，占 **62.2%**。但这类统计是网格视角；对零出力场站的解释应优先使用场站视角，即“场站落在缺测格点上，且缺测被 CF 脚本转为 0”。

## 四、传播链

### 步骤 1：BCSD 输出产生 `NaN`

`ref_code/bcsd/step06_apply_sd_3h.py` 中，最终输出前会用高分辨率观测覆盖掩膜裁剪结果：

```python
mask_src = ds_hi[var].isel(time=0).notnull()
...
part = part.where(mask_src)
```

这会把 `obs_hi` 中无覆盖的格点保留为 `NaN`。这些格点有两类：

- 海洋/海岸格点：ERA5-Land 本身无有效陆面气象值。
- bbox 边界陆地格点：粗 GCM 网格到 0.1° 网格插值及区域裁剪导致边缘无法外推，最终被 `mask_src` 重新置为 `NaN`。

对场站影响最大的是第二类。它不是“场站在海上”，而是“陆地场站所在的 BCSD 网格没有有效气象输入”。

### 步骤 2：CF 计算把气象 `NaN` 转成 0

光伏：

```python
def to_kw_m2(arr, units):
    ...
    out = np.nan_to_num(out, nan=0.0, posinf=0.0, neginf=0.0)
    return np.maximum(out, 0.0)
```

风电：

```python
def wind_to_ms(arr, units):
    ...
    x = np.nan_to_num(x, nan=0.0, posinf=0.0, neginf=0.0)
    return x
```

随后脚本只恢复海洋格点：

```python
cf_chunk = np.where(land_mask[None, :, :], cf_chunk, np.nan)
```

如果 `global_land_mask` 判断该格点为陆地，那么源气象缺测已经被转成 0，无法再恢复为 `NaN`。这正是零 CF 的直接来源。

### 步骤 3：场站最近邻匹配正常，但取到的是零值格点

`ref_code/calculate_wind_solar_out/station_output_calculator_0p1deg.py` 对场站做最近邻取值：

```python
cf_pts = cf_slab[:, lat_rel, lon_rel]
block = np.where(np.isnan(cf_pts), np.nan, cf_pts * capacities[None, :])
```

排查显示零出力场站的 `match_dist_deg` 很小，中位数约 `0.000003°`，远低于 `0.15°` 容差。因此不是配准失败，而是场站确实匹配到了 `CF = 0` 的网格。

### 步骤 4：RQ1 年度统计把全年 0 当作有效数据

`RQ1/prepare_RQ1_data.py`：

```python
has_data = ~np.all(np.isnan(yr_power), axis=0)
pwr_sum = np.nansum(yr_power[:, idx], axis=0)
ann_cf = pwr_sum / (n_yr_steps * cap_gw[idx])
```

`has_data` 只排除全年全 `NaN` 的场站；全年全 0 的场站仍满足 `has_data=True`，所以会进入 `station_annual_generation.csv`，并得到 `ann_cf = 0`、`annual_generation = 0`。

## 五、已排除的假设

| 假设 | 排查结果 |
|------|---------|
| 场站与 CF 格点配准失败 | 否。零出力场站 `match_dist_deg` 极小，配准正常 |
| `activation_year > 目标年` | 否。零出力场站中存在 2030、2040 激活场站，到 2050 已激活 |
| 场站落在 CF 文件覆盖范围外 | 否。多数场站在覆盖区内，只是匹配到的 CF 值为 0 |
| 出力 NC 读取失败或区域文件缺失 | 否。文件存在且读取正常 |
| 真实物理全年零发电 | 基本否。风光全年 CF 精确为 0 且大面积集中在缺测边界，不符合物理预期 |

## 七、处理建议

### 7.1 短期：保留现有绘图过滤，但明确语义

当前 RQ1 绘图过滤 `CF = 0` 或 `generation = 0` 是合理的，因为这些点大概率是数据缺测伪影，不应进入 CF 分布图或象限图。建议在图注或方法说明中明确：

> 已剔除全年出力为 0 的场站；这些场站主要来自 BCSD 气象缺测被 CF 脚本转写为 0，不代表真实全年无发电。

### 7.2 中期：修复 CF 计算，保留源气象缺测为 `NaN`

最关键的修复应放在 `S01E01_Simulate_Solar_CF_BCSD.py` 和 `S01E02_Simulate_Wind_CF_BCSD.py`。原则是：**可以继续用 `nan_to_num` 保护计算过程，但计算后必须把源输入缺测的位置恢复为 `NaN`。**

风电建议：

```python
source_valid = np.isfinite(uas_raw) & np.isfinite(vas_raw)

uas_ms = wind_to_ms(uas_raw, uas_units)
vas_ms = wind_to_ms(vas_raw, vas_units)
cf_chunk = compute_wind_cf_chunk(...)

cf_chunk = np.where(source_valid, cf_chunk, np.nan)
cf_chunk = np.where(land_mask[None, :, :], cf_chunk, np.nan).astype(np.float32)
```

光伏建议：

```python
source_valid = (
    np.isfinite(rsds_raw)
    & np.isfinite(tas_raw)
    & np.isfinite(uas_raw)
    & np.isfinite(vas_raw)
)

rsds_kw = to_kw_m2(rsds_raw, rsds_units)
tas_c = tas_to_celsius(tas_raw, tas_units)
cf_chunk = compute_solar_cf_chunk(...)

cf_chunk = np.where(source_valid, cf_chunk, np.nan)
cf_chunk = np.where(land_mask[None, :, :], cf_chunk, np.nan).astype(np.float32)
```

这样，`station_output_calculator_0p1deg.py` 会把这些点输出为 `power = NaN`，`prepare_RQ1_data.py` 的 `has_data` 也能正确排除全年全缺测场站。

### 7.3 中长期：修复 BCSD 边界缺测

如果希望从源头改善数据质量，可考虑在 `ref_code/bcsd` 层处理 bbox 边界缺测：

1. 对每个国家 bbox 增加缓冲区做 BCSD，完成后再裁剪回目标区域，降低插值边缘外推失败。
2. 对 `mask_src` 的陆地边界 `NaN` 做受控最近邻填补，但要保留海洋 `NaN`，并输出填补比例诊断。
3. 在 BCSD 输出文件中写入有效覆盖率、陆地缺测率、边界带宽度等属性，便于后续自动质控。

### 7.4 下游防线

即使修复 CF 生成，也建议在 RQ1 数据准备阶段加一道诊断：

- 输出每个 `(ssp, year, technology)` 的 `ann_cf == 0` 数量与容量占比。
- 对全年全 0 的场站增加标记列，例如 `zero_generation_flag`。
- 若某个区域/国家零出力比例异常升高，直接报警，而不是只在绘图脚本中静默过滤。
