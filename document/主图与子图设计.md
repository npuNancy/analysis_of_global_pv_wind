# 极端事件与风光损失：主图与子图设计

小凯，这份设计承接[故事逻辑参考](故事逻辑参考.md)，将五个故事点细化为 **5 张主图、28 个子图**。这是可以据数据落实的图件方案，尚未计算结果或生成图片；图中的方向、差值和国家案例均不预先指定。

核心设计是：**每张图回答一个主要问题，每一行子图推进一个证据层次；风电与光伏通常左右对照，信息密度通过共用坐标、颜色、图例和有意义的叠加获得。** 28 个子图是完整候选版，最终可删去没有新增发现的子图。

## 一、常用图型应该怎样选

Nature 系列并没有一套必须凑齐的图型清单。官方指南强调，多个子图应有逻辑联系，图件应以清晰为前提保持简洁，避免无必要的子图与复杂细节。[Nature 图件与图注指南](https://www.nature.com/nature/for-authors/formatting-guide)

### 1.1 按科学问题选择图型

| 要回答的问题 | 常用图型 | 适合承载的信息 | 对本研究的用途与取舍 |
|---|---|---|---|
| 不同组的数值差多大？ | 分组柱状图、水平条形图、点区间图／森林图 | 组间水平、差值、模型范围 | 比较 SSP 和国家时，点区间图通常比密集分组柱更节省空间；柱图从零起画。 |
| 同一对象在两种条件下如何改变？ | 哑铃图、配对散点图、斜率图 | 起点、终点、方向和差距 | 对照 SSP126 与 SSP585；SSP245 可作为第三个参照点。 |
| 随时间如何演变？ | 折线图、折线＋阴影带 | 时间轨迹、模式范围或其他明确区间 | 阴影须说明是模式极差、分位区间还是置信区间，不能含混地写“误差”。 |
| 各部分占多少？ | 堆叠柱、100% 堆叠条、堆叠面积图 | 可相加的数量或构成份额 | 适合互斥的国家响应类别；重叠的极端事件标签不能直接作为总损失构成。 |
| 数据如何分布？ | 箱线图、小提琴图、雨云图、直方图 | 中位数、离散度、偏态、异常值 | 多个国家可画箱线＋散点；只有四个模式时优先直接画四点，避免用平滑小提琴制造丰富分布的印象。 |
| 超过某损失水平的年份有多少？ | 经验累计分布 ECDF、经验超越曲线 | 整个分布及高损失端 | 不依赖直方图分箱；需明确是样本内年度比例，并交代每模式的年数。 |
| 两个量如何共同变化？ | 散点图、气泡图、散点＋边际分布、六边形分箱 | 二维关系，另用颜色／面积编码分组／规模 | 国家数量适合散点；海量格点适合分箱。不要把点数当作独立气候样本量。 |
| 差异出现在哪里？ | 格点地图、国家分级设色图、地图＋比例符号 | 空间格局、强度、资产分布 | 区分连续格点气候量与国家汇总量；气泡面积可编码容量，地图颜色编码差值。 |
| 多个国家、时期、事件如何对照？ | 热图、气泡矩阵、点阵图 | 两个分类维度及一个／两个数值维度 | 国家×时期用热图，事件×SSP 可用气泡矩阵。不要逐列归一化后仍把颜色称为实际损失。 |
| 总差值由哪些项构成？ | 瀑布图、正负贡献条形图 | 可加分解、抵消与净效应 | 全球用瀑布，多个国家用水平正负贡献条更紧凑。 |
| 风险是否集中在少量资产？ | 排序累计曲线、集中度曲线 | 累计容量与累计负担 | 用于 Fig. 5；须说明排序变量及负净损失处理，不将集中度曲线误称优化收益。 |
| 类别或流向如何迁移？ | 桑基图、alluvial 图、转移矩阵 | 同一对象的类别转移、实际流量 | 跨年代国家类别转移可用；连带宽度必须是真实数量。当前主线用热图更容易保留差值幅度。 |
| 多维画像是什么？ | 雷达图、平行坐标图 | 多项标准化指标 | 可作补充画像，但精确比较较困难；单位不同必须交代标准化，主图优先点图或热图。 |
| 简单的总体组成是什么？ | 饼图、圆环图 | 少数互斥类别占比 | 可以做单个概览；多个国家或 SSP 的份额对照优先共用基线的 100% 条形图。不推荐 3D 饼图。 |
| 分析对象或过程是什么？ | 概念示意、流程图、事件时间轴 | 概念、阈值、连接关系 | 需要澄清事件定义时可放方法或补充图；不要占用主图重复展示已经完成的上游流程。 |

### 1.2 高信息密度组合：组合的是互补信息

| 组合方式 | 各部分分别表达什么 | 适合放在哪里 |
|---|---|---|
| **地图＋空心容量气泡** | 底色：气候变化；气泡位置：部署；气泡面积：容量 | Fig. 1a–b。 |
| **折线＋阴影＋年度点** | 粗线：集合中心；阴影：模式范围；点：年度值 | Fig. 2a–b。 |
| **区间线＋四模式小点＋集合大点** | 范围、各模式结果和中心同时可见 | Fig. 2c–d。 |
| **箱线＋国家散点＋全球菱形** | 国家分布、个体异质性和全球容量加权结果 | Fig. 3e。 |
| **热图＋一致性标记** | 色彩：差值幅度；标记：模式方向是否一致 | Fig. 3c–d。 |
| **贡献条＋净差值菱形** | 正负项的抵消，以及抵消后的净差值 | Fig. 4c–d。 |
| **哑铃＋中间路径参照点** | 两端路径差及 SSP245 是否位于两端之间 | Fig. 4e–f。 |
| **二维气泡图＋参考线** | SSP126 损失、路径差、容量和相对高负担区 | Fig. 5a–b。 |

“柱状＋折线”也可使用，但只有共享一个纵轴量纲，或两组轴有明确物理关系时才容易准确阅读。**两个任意缩放的纵轴会制造视觉相关性**；本方案优先使用对齐的小面板。Inset 小插图应承担必要概括或局部放大，不再堆放重复的主图结果。

## 二、所有图共用的定义与视觉规则

### 2.1 指标、时段和参考容量

以下计算均先在单个气候模式内完成，再对四模式等权汇总。风电与光伏分别计算；单位装机指标的分母采用所属情景、窗口及有效样本的容量。

| 符号 | 含义 | 图中单位 |
|---|---|---|
| $h_g$ | 格点每年落在至少一种适用事件中的时间；按时间并集去重 | h yr⁻¹ |
| $E$ | 场站容量加权的年均事件暴露时数，$E=\sum_i C_i h_i/\sum_i C_i$ | h yr⁻¹ |
| $E_e$ | 事件类型 $e$ 的容量加权年均暴露时数 | h yr⁻¹；不同类型可能重叠 |
| $R$ | 全部事件年均净损失总量／容量总量 | MWh MW⁻¹ yr⁻¹ |
| $R_e$ | 某事件标签下年均净损失／该分析范围全部有效装机 | MWh MW⁻¹ yr⁻¹；分母不只取发生该事件的站点 |
| $D$ | $R_{585}-R_{126}$；正值为 SSP585 损失更高 | MWh MW⁻¹ yr⁻¹ |
| $\Delta E$ | $E_{585}-E_{126}$；正值为 SSP585 暴露更多 | h yr⁻¹ |
| $\mathrm{CF}_{\rm ev}$ | 事件窗口反事实发电量／装机加权事件小时 | 无量纲 |
| $r_{\rm ev}$ | 事件窗口净损失／该窗口反事实发电量 | 无量纲；若画百分数需乘 100 |
| $C^{\rm ref}$ | **SSP126 的 2050s 快照参考容量**，用于气泡面积和跨图固定权重展示 | GW；底层计算通常为 MW |

默认时期为 **2030–2039、2040–2049、2050–2059**。空间对比和类型分析以 2050–2059 为主；时间轨迹保留三个窗口。参考容量不随所比较的 SSP 改变，避免气泡大小本身改变而干扰对差值的阅读。它不替代各路径计算 $R$ 时的真实分母。

需在实施时确认四模式是否有共同有效空间支持，并报告损失分析有效容量与参考容量的覆盖关系。没有数据与确实为零必须分开；没有装机时，单位装机指标未定义，不能填零。

### 2.2 配色和符号

- **SSP 配色沿用仓库：** SSP126 深蓝 `#1d3b6f`，SSP245 赭黄 `#b77c19`，SSP585 深红 `#9e1b1b`。在配对点图中再用圆／方／三角区分，增强灰度可读性。
- **差值配色：** 蓝—浅色—红，以零为中心；红表示目标路径的数值更高，不自动等同于某种政策判断。地图与热图的比较对象在标题中明确。
- **分解项配色：** 沿用仓库的暴露、事件资源、事件损失率颜色，并附固定名称；净差值用深灰。因子颜色表示“是哪一项”，正负由条的位置表达。
- **技术主要由列位置区分：** 左风电、右光伏；不再为技术叠加另一套主配色。
- **点的面积与容量成正比，不能让半径与容量成正比。** 提供至少三个容量示例圆。若空间跨度太大而改用其他尺度，必须改写图例，不能继续称面积正比。
- **同量纲且用于直接比较的图共用范围。** 无法共用时明确给出各自色条和上下限；不通过偷偷改变坐标范围夸大或缩小差异。

### 2.3 不确定性不是一种统一的“误差带”

| 表达 | 在本方案中的含义 | 图注必须写清 |
|---|---|---|
| 四个模式小点 | 四个 GCM 各自计算的结果 | 模式为 CANESM5、MPI-ESM1-2-HR、MRI-ESM2-0、BCC-CSM2-MR。 |
| 线或点的范围带 | 四模式最小值—最大值 | 是模式范围，不是 95% 置信区间。 |
| 国家箱线图 | 每国一个四模式均值构成的国家分布 | 国家数、国家等权、箱体与须定义；不是气候模式不确定性。 |
| 年度经验超越曲线 | 某一窗口各年度损失的样本内超越比例 | 每模式 10 年，不能说成 40 个相互独立的气候实现。 |
| 地图／热图的一致性标记 | 至少 3/4 模式与集合平均差值具有相同的非零方向 | 只表示方向一致性，不表示统计显著性或发生概率；多数模式与均值异号时归入方向不明确。 |

四模式在论文中是有限的气候集合，不足以支撑细致的概率校准。分类与标记需同时保留差值幅度，避免把数值极小的同号结果写成重要影响。

## 四、Fig. 1：极端事件的路径差异

**待检验的论点：** 极端事件的路径差异在空间、年代和事件类型之间并不均一，并影响风光装机的暴露。

**布局：** 第一行为 a 风电地图、b 光伏地图；第二行为 c 风电暴露轨迹、d 光伏暴露轨迹；第三行为 e 风电事件矩阵、f 光伏事件矩阵。地图回答“哪里”，轨迹回答“何时”，矩阵回答“什么事件”。

### a｜风电：变化发生在哪里，是否与部署区重合？

- **图型：世界格点地图＋参考容量气泡。** 主角是气候事件变化，容量气泡是部署位置背景。
- **横／纵空间坐标：** 经度／纬度，单位为 °；可用 Robinson 投影，地图经纬网标注地理角度，不把投影坐标当作公里。
- **颜色：** 2050s 格点全部事件年均小时差 $h_{g,585}-h_{g,126}$，单位 h yr⁻¹。先逐模式计算差，再平均；保持零中心发散色标。
- **气泡：** 按固定展示网格汇总 $C^{\rm ref}$，圆面积对应 GW；使用浅灰空心圆，避免遮盖底色。可先采用 1° 展示网格，最终按图面密度调整并记录。
- **画法：** 气候统计仍来自原始分析尺度；若地图需要降采样展示，先做有定义的面积加权聚合，不能直接抽点代替统计。容量气泡只是固定部署参照，不用于重新计算底色。
- **一致性：** 可用稀疏斜线标记模式方向不一致区；若与容量圆叠加过密，把一致性地图放补充图，主图保留最必要的两层信息。

### b｜光伏：其风险空间格局是否与风电相同？

- **图型、坐标和单位：** 与 a 相同，替换为光伏适用事件及参考光伏容量。
- **比较方法：** a、b 优先共用同一 h yr⁻¹ 色条、投影和地理范围；两图的气泡面积标度也一致。
- **要说明的内容：** 两技术是否面对不同的事件变化区域，而不是仅比较哪张图看起来更红。海上或陆地区域是否纳入由有效研究范围决定，不能将海上风电一并遮掉。

### c｜风电：装机所经历的暴露在三个时期如何变化？

- **图型：折线＋四模式点＋范围线／浅阴影。**
- **横轴：** 2030s、2040s、2050s，轴注给出完整十年范围。
- **纵轴：** 全球容量加权事件暴露 $E$，h yr⁻¹。
- **颜色／符号：** 三种 SSP 各一条线；每个时期用小点展示四模式、大点展示均值，细线展示 min–max。
- **画法：** 仅连接三个窗口均值，不生成平滑曲线或虚构逐年数据。容量按各情景、快照使用；若快照部署改变，图注说明这不是固定场站队列。
- **要说明的内容：** 路径差是一直存在、后期扩大，还是没有稳定排序。

### d｜光伏：其暴露轨迹是否遵循同样的路径排序？

- **图型及横轴：** 与 c 相同。
- **纵轴：** 光伏的 $E$，h yr⁻¹；优先与 c 共用纵轴范围。
- **画法：** 与 c 共用 SSP 图例、模式范围说明和时期标签，直接标注技术名称。
- **要说明的内容：** 风光之间的轨迹差异，以及 SSP245 是否总处于两个端点路径之间。

### e｜风电：哪些事件构成更长的暴露，哪些变化更大？

- **图型：气泡矩阵，兼用面积与颜色。**
- **横轴：** SSP126、SSP245、SSP585，分类轴，无数值单位。
- **纵轴：** 上游已定义的风电事件类型，分类轴；不新增未经识别的事件名称。
- **圆面积：** 2050s 的 $E_e$，h yr⁻¹，给出独立的大小图例。
- **圆颜色：** 该列 SSP 相对 SSP126 的 $\Delta E_e$，h yr⁻¹；因此 SSP126 列使用零差值中性色，面积仍表示其暴露水平。
- **画法：** 行顺序按 SSP126 暴露水平固定，三列完全一致；不适用／缺失用明确符号，零暴露可用小叉而非可见面积圆。
- **要说明的内容：** “绝对暴露很大”和“路径变化很大”是两件事。某类型可以圆大但颜色浅，也可以圆小但颜色深。
- **限制：** 各事件可能重叠，气泡面积不能相加解释为全部事件暴露。全部事件并集若另列，应与分类行用间隔分开。

### f｜光伏：其主导暴露类型是否不同？

- **图型及横轴：** 与 e 相同。
- **纵轴：** 光伏适用事件类型；共同类型尽量与 e 保持相同相对顺序。
- **圆面积／颜色单位：** 均为 h yr⁻¹，分别表示 $E_e$ 和相对 SSP126 的差值。
- **画法：** e、f 共用面积和差值图例，尽量控制在约 6–8 个适用类型；如果类型更多，扩展矩阵或完整结果放补充图，不按结果好坏删类。

**本图数据需求：** 格点事件并集时数、各类型事件时数、场站容量与时数、四模式及各 SSP 的一致有效掩膜。**审阅重点：** a–b 是固定格点气候比较，c–f 是各路径部署上的容量加权暴露，二者不会在部署不同的情况下自动等价。

## 五、Fig. 2：全球单位装机损失的路径差异

**待检验的论点：** 极端事件造成的单位装机损失具有可量化的路径差异，其平均水平和高损失年份表现可能不同。

**布局：** 左列风电、右列光伏；a–b 绝对损失轨迹，c–d 配对路径差，e–f 年度经验超越分布。

### a｜风电：每 MW 装机每年损失多少？

- **图型：年度折线＋模式范围阴影。**

## 七、Fig. 4：损失差的来源

**待检验的论点：** 路径差可由暴露、事件期资源和相对损失率共同解释，不同国家可能具有不同的贡献组合。

本图采用仓库已有三因子口径：

$$
R=E\,\mathrm{CF}_{\rm ev}\,r_{\rm ev},\qquad
D=\phi_E+\phi_{\rm CF}+\phi_r
$$

三个 $\phi$ 使用六种因子替换顺序平均的对称 Shapley 分解，单位均为 **MWh MW⁻¹ yr⁻¹**。先逐模式、逐窗口分解，再平均贡献；三项之和必须闭合到同口径路径差。因子本身虽然单位不同，**分解贡献全部具有损失差的单位**。

若某范围出现零暴露或零事件期反事实发电量，三因子比值没有定义，需单列说明或改用有定义的较粗分解；不能硬加小量后继续排名。

**布局：** a–b 全球三因子瀑布，c–d 代表国家水平贡献条，e–f 事件损失哑铃。固定比较 2050s SSP585−SSP126；其他时期作为补充对照。

- **模式信息：** 在最终 $D$ 柱旁画四个模式差值点；因子各模式结果放对应数据表或补充分解图，避免给浮动柱叠加含义不清的误差线。

- **国家排序：** 按 2050s SSP126 的四模式平均 $R_{126,c}$ 从高到低排列；该顺序在各模式曲线中固定。
- **横轴：** 排序后累计参考容量／可比较国家参考容量总量，0–100%。
- **纵轴：** 累计正净损失负担／全部正净损失负担，0–100%。在模式 $m$ 中，国家负担定义为 $B_{c,m}^{+}=C_c^{\rm ref}\max(R_{126,c,m},0)$。
- **画法：** 先逐模式计算累计负担份额，再画四模式均值曲线与范围。参考容量和可比较国家集合必须相同；连线经过真实国家累计端点，标出前 5 国／前 10 国的位置。
- **参照：** 绘制浅灰 1:1 线，表示容量份额与负担份额相同；曲线反映强度排序后的集中程度。
- **要说明的内容：** 关注较高损失国家涉及多大装机规模和负担，不再重复 a 中的二维关系。
- **边界：** 这里的正值截取只用于“正净损失负担”的集中度，不能回头替代其他图的有符号净损失。它也不等于逐时正损失，因为国家内部增益已先与损失相抵。排序本身使曲线倾向于显示集中，不能据此宣称显著关系或最优适应收益。

### d｜光伏：其剩余负担是否比风电更集中？

- **图型及坐标：** 与 c 相同，横纵轴都固定 0–100%。
- **计算：** 光伏独立排序，使用参考光伏容量及各模式 $R_{126,c,m}$；不要沿用风电的国家排序。
- **画法：** 与 c 共用线型、范围带和标记规则。四模式的集中程度不一致时用范围体现，不只强调均值曲线。
- **要说明的内容：** 相同的容量份额是否对应不同的负担份额，从而说明两技术关注重点的集中程度。
- **未定义情形：** 若某模式的正净损失总量为零，份额无定义，应明确标记；若所有模式均如此，c／d 改为有符号国家损失排序图，不能强制画累计比例。

**本图数据需求：** 国家级 SSP126 和 SSP585 损失、参考容量、四模式结果及固定国家名单。计算 $B^+$ 时，参考容量与 $R$ 所代表的有效装机须一致；否则只能称参考权重下的负担指数，不能称实际总损失。

**本图结论范围：** 识别值得优先进一步分析的国家与资产规模；既不把 SSP126 的全部剩余损失称为不可避免，也不直接给出储能容量、输电投资或选址优化收益。

每个子图至少保存对应的源数据表，含模式、情景、技术、国家／格点、时期、数值、单位和有效覆盖信息。图注交代中心统计量、范围定义和实际样本量。Nature 对统计图注也要求明确误差线与统计量的含义。[Nature 图注要求](https://www.nature.com/nature/for-authors/formatting-guide)

### 9.2 有价值但暂不挤入主图的内容

| 补充内容 | 图型与坐标设计 | 能增加的证据及前提 |
|---|---|---|
| **固定部署对照** | 配对点区间图；x 为国家或全球，y 为 SSP585−SSP126 损失差，MWh MW⁻¹ yr⁻¹；分别画各路径部署与共同部署结果 | 区分路径综合差异和固定部署下的气候差异。若要将主结论称为“气候减缓收益”，此对照需提升为重要证据，而非只藏在补充材料。 |
| **季节—事件损失矩阵** | x 为 DJF／MAM／JJA／SON，y 为事件类型，颜色为季节损失差对年均损失的贡献，MWh MW⁻¹ yr⁻¹ | 将年度损失定位到月份季。需要季节或更细时间数据；跨季事件按损失发生时段分配，不能只按事件起始日归季。南北半球统一标月份，不统一称冬夏。 |
| **事件频次与单次持时** | 配对点图／频次—持时散点；x 次 yr⁻¹，y h event⁻¹，颜色为 SSP | 区分暴露增长来自“更多次”还是“每次更久”；需要可靠事件目录，不能从全年累计小时反推两者。 |
| **暴露差与损失差** | 国家散点；x 为 $\Delta E$，h yr⁻¹；y 为 $D$，MWh MW⁻¹ yr⁻¹；点面积为参考容量 | 直接检验事件变化与能源后果的方向是否一致。属于关系描述，不能代替三因子核算，更不能用未经处理的空间相关样本做过强显著性推断。 |
| **全年损失率对照** | 配对散点或点区间图；x 为 SSP126，y 为 SSP585 的全年反事实发电损失率，均为 %，加 1:1 线 | 检验按发电量归一化后路径排序是否改变；必须使用全年反事实分母，不能替换成事件期分母。 |
| **全部国家与四模式结果** | 全国家热图、按模式分面的地图、点区间图 | 检验主图案例代表性与模式依赖；完整数据可查询。 |
| **10 km 与聚合尺度比较** | 国家路径差配对散点；x 为较粗尺度，y 为 10 km 结果，均为 MWh MW⁻¹ yr⁻¹，加 1:1 线 | 若主张高分辨率改变风险判断，需有实际对照；地图看起来更细不构成效果证据。 |

本方案没有把储能、输电、需求或选址优化画成结果，因为现有主故事不需要这些新增模型。若后续确有干预结果，应以干预前后对照替换相应结尾子图，而非仅加一个“解决方案”示意图。

## 十、版面与交付约定

### 10.1 版式草图

Fig. 1、Fig. 2、Fig. 4 采用相同的技术列结构，但按内容分配行高：

```text
                    Wind                         Solar
             ┌─────────────────┐          ┌─────────────────┐
  主要证据   │ a               │          │ b               │
             └─────────────────┘          └─────────────────┘
             ┌─────────────────┐          ┌─────────────────┐
  第二层次   │ c               │          │ d               │
             └─────────────────┘          └─────────────────┘
             ┌─────────────────┐          ┌─────────────────┐
  第三层次   │ e               │          │ f               │
             └─────────────────┘          └─────────────────┘
```

Fig. 3 上两行仍是左右技术对照，下排 e 为两技术国家分布，f 为两技术的国家数／容量份额。Fig. 5 只有两行，给主要二维关系更大面积。版式骨架可以统一，子图高度不必平均。

### 10.2 尺寸、文字和输出

- **初始排版按双栏约 183 mm 宽设计。** Fig. 1–4 可先控制在约 150–165 mm 高，Fig. 5 约 140–165 mm；这是本方案的起始版面，最终按具体子刊调整。Nature 本刊公开指南给出 89／183 mm 的单／双栏宽度及相应字体、版面要求，不能自动视为所有子刊相同。[官方排版指南](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)
- **最终尺寸下正文和刻度约 6–7 pt，子图字母约 8 pt 加粗。** 小写 a、b、c 按阅读顺序放左上角；国家标签过密时减少主图名单，不无限缩小字体。
- **共享图例和色条。** SSP 图例放一处；相同单位、相同尺度的两张地图共用色条。容量面积、差值颜色、模型范围各有自己的明确说明，不能用一个含混“大小／颜色表示风险”的图例代替。
- **减少装饰。** 白底、淡化网格、不使用 3D 柱或 3D 饼；边界线、参考线和主数据具有不同线重。
- **沿用 Python/matplotlib。** 本次只形成设计文档，未来实际绘图与视觉检查沿用同一后端；大内存统计与绘图通过 SLURM 执行。
- **项目图片仍只输出 600 dpi PNG。** 保留脚本及源数据，使版面可以重建；PNG 是本项目的分析与审阅输出，不将它视为已满足所有目标期刊最终制作格式的声明。

### 10.3 每个图注必须回答的六件事

1. 比较了什么：SSP、技术、时期、空间对象及是否固定部署。
2. 横轴、纵轴、颜色、面积、符号分别表示什么，单位是什么。
3. 一个点／一个格子／一条线代表一个国家、年度、格点还是模式。
4. 大点或粗线采用什么中心量，阴影或区间表示什么范围。
5. 缺失、无装机、负净损失和事件重叠如何处理。
6. 对应子图的源数据及有效覆盖是多少。

## 十一、实施前最后确定的事项
